## Selected Projects

**[AI Art Studio (AI-Art-Style-Transfer)](https://github.com/mohammednaeemog-sys/AI-Art-Style-Transfer)**
A local-first image stylization application with 18 selectable styles. Combines Stable Diffusion, Canny ControlNet, LoRA adapters, and fast neural style models behind a Gradio interface, with adjustable style strength, structure preservation, and seed control. Runs inference locally without a paid API. Python, PyTorch, Diffusers, Gradio.

**[Password Strength Classification Using Structural Features](https://github.com/mohammednaeemog-sys/Password-Strength-Classification-Using-Structural-Features)**
Machine learning classification of password strength from structural features, using a stacking ensemble. Python, Jupyter Notebook.

**[Image Classification Using a Convolutional Neural Network](https://github.com/mohammednaeemog-sys/-Image-Classification-Using-Convolutional-Neural-Network)**
Image classifier built with a convolutional neural network. Jupyter Notebook.

**[Penetration Testing and Remote Access Simulation](https://github.com/mohammednaeemog-sys/Penetration-Testing-and-Remote-Access-Simulation-Using-Kali-Linux-and-Metasploit-Framework)**
Simulated penetration test and remote access scenario using Kali Linux and the Metasploit Framework.

**[RRN-WORK](https://github.com/mohammednaeemog-sys/RRN-WORK)**
Neural network experiments in Jupyter Notebook.

## Collaborative Work

**[EWU Bulletin RAG Chatbot](https://github.com/mohammednaeemog-sys/rag-project-bluebook)**
A local, citation-grounded retrieval-augmented generation chatbot over the East West University Undergraduate Bulletin. Uses hybrid dense and BM25 retrieval with reranking, a locally served LLM, and deterministic citation and number validation, evaluated on hand-checked question sets. Fork of a project by [mishkat2025](https://github.com/mishkat2025/rag-project-bluebook).
